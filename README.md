# Frontend Recreation Challenge from https://www.frontendpractice.com/projects

A collection of real-world website recreations built from scratch to strengthen my frontend development skills.

Each project is recreated as closely as possible to the original design using primarily **HTML and CSS**.

## Projects

### 1. Ableton

**Level:** 1

A recreation of the Ableton About page.

**Focus:**

- Semantic HTML
- CSS layout
- Flexbox
- Typography
- Spacing
- Responsive design
- Images and media

[View Project](./Ableton)

---

### 2. Starbucks

**Level:** 2

A recreation of the Starbucks Rewards page.

**Focus:**

- More advanced layouts
- Flexbox and CSS Grid
- Responsive design
- Navigation
- Cards and sections
- Complex spacing and positioning

[View Project](./Starbucks)

## Learning Goals

The purpose of this repository is to move beyond isolated HTML and CSS exercises and practice building complete, real-world interfaces.

Through these projects, I am focusing on:

- Writing semantic HTML
- Building layouts with Flexbox and CSS Grid
- Creating responsive websites
- Understanding CSS positioning
- Working with typography and spacing
- Using pseudo-elements
- Creating reusable CSS patterns
- Improving visual accuracy
- Writing clean and maintainable code
